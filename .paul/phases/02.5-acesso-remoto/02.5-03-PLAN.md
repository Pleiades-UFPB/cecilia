<objective>
## Goal
Permitir que um contribuidor autenticado liste datasets, baixe blobs com retomada e paralelismo, materialize em `data/raw/`, verifique a integridade e emita as linhas do manifesto de dados.

## Purpose
O servidor do 02.5-02 já entrega catálogo, manifestos e blobs. Falta o lado que o grupo realmente usa: um comando simples que transforma `dataset@versão` em arquivos locais verificados, sem rebaixar o que já está em cache.

## Output
- `config.py` — URL, chave, alias, cache e diretório de dados
- `client.py` — catálogo, manifesto e whoami
- `download.py` — download único, em chunks paralelos, retomada e retry
- `sync.py` — materialização em `data/raw/`, estado local e linhas do manifesto
- `remote/cli.py` — `login`, `list`, `manifest`, `sync`, `get`, `verify`, `doctor`
- Testes com o servidor real via ASGI, cache temporário e transporte que conta requisições
</objective>

<acceptance_criteria>

## AC-1: Configuração e login seguros
```gherkin
Given uma URL HTTPS e uma chave de API
When `cecilia remote login` é executado
Then a chave é lida sem eco, validada em `/v1/whoami`, gravada em arquivo 0600 e a URL é normalizada
And HTTP fora de localhost é recusado salvo `CECILIA_INSECURE=1`
```

## AC-2: Catálogo e manifesto legíveis
```gherkin
Given uma chave válida
When `cecilia remote list` ou `cecilia remote manifest` é executado
Then mostra dataset, versão, arquivos, linhas, bytes, hash do manifesto e caminhos
And `--json` devolve o payload original para automação
```

## AC-3: Sync materializa e reaproveita
```gherkin
Given um dataset publicado e um diretório de dados vazio
When `cecilia remote sync` é executado
Then os arquivos aparecem em `data/raw/<dataset>/<versão>/` com SHA-256 conferido
And o cache guarda blobs por hash, o estado local é escrito e as linhas do manifesto são emitidas
And um segundo sync não rebaixa blobs já presentes
```

## AC-4: Retomada e paralelismo corretos
```gherkin
Given um download interrompido ou um blob grande
When o cliente retoma ou usa várias conexões
Then o arquivo final tem o SHA-256 do manifesto
And o cliente respeita o limite de conexões e não rebaixa o que já está completo
```

## AC-5: Verificação e diagnóstico
```gherkin
Given arquivos sincronizados
When `cecilia remote verify` é executado após corromper um arquivo
Then o problema é apontado e o comando termina com código 1
And `cecilia remote doctor` informa autenticação, latência e throughput de uma faixa
```
