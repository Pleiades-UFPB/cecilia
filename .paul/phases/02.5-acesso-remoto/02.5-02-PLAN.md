<objective>
## Goal
Servir catálogo, manifestos e blobs publicados por HTTP, autenticando com chave de API, registrando cada acesso e limitando requisições e conexões concorrentes.

## Purpose
O 02.5-01 fechou o formato de publicação. Falta o transporte: sem servidor, o CLI do 02.5-03 não tem o que consumir. Este plano expõe os artefatos já verificados, sem adicionar computação no servidor e sem rotas administrativas.

## Output
- `settings.py` — configuração por ambiente, com pepper obrigatório
- `auth.py` — chaves HMAC-SHA256, expiração e revogação em SQLite
- `audit.py` — registro de acesso com bytes, status e IP
- `ratelimit.py` — janela deslizante e concorrência por chave
- `index.py` — índice blob → dataset/arquivo para auditoria
- `server.py` — app FastAPI com `/health`, `/v1/catalog`, manifestos, blobs e `/v1/whoami`
- CLI `cecilia admin key` e `cecilia admin log`, mais `cecilia serve`
- Testes de auth, auditoria, limites, Range/ETag e CLI
</objective>

<acceptance_criteria>

## AC-1: Chave de API com expiração e revogação
```gherkin
Given um servidor com pepper configurado
When `cecilia admin key create --alias luan` é executado
Then o token é exibido uma única vez, o banco guarda apenas HMAC-SHA256 e a chave expira em 90 dias
And uma chave expirada ou revogada é recusada com 401 sem servir bytes
```

## AC-2: Servidor somente leitura com Range e ETag
```gherkin
Given um dataset publicado e uma chave válida
When o cliente pede catálogo, manifesto ou blob
Then recebe 200 com ETag; um GET com If-None-Match recebe 304
And um GET de blob com Range recebe 206 com os bytes exatos e Content-Range
```

## AC-3: Auditoria registra quem, o quê e quanto
```gherkin
Given um acesso autenticado a um blob
When a resposta termina
Then a auditoria registra apelido, dataset, versão, arquivo, bytes enviados, status, IP e duração
And tentativas sem chave ou com chave inválida também são registradas, sem Authorization
```

## AC-4: Limites, concorrência e contenção
```gherkin
Given os limites configurados
When uma chave excede o limite de requisições ou de conexões simultâneas
Then recebe 429 e o evento é auditado
And caminho com `..`, blob não publicado e dataset desconhecido não servem nada fora da raiz
```

## AC-5: Administração local e superfície mínima
```gherkin
Given o servidor em execução
When a superfície HTTP é inspecionada
Then não existe rota administrativa e o app só lê `/srv/cecilia/blobs`
And `cecilia admin key list|revoke` e `cecilia admin log` funcionam localmente no servidor
```
