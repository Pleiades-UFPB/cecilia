<objective>
## Goal
Publicar um diretório de Parquets como um dataset imutável em `/srv/cecilia`, com blobs endereçados por SHA-256, manifesto verificável e catálogo reconstruível, usando a CLI `cecilia admin`.

## Purpose
A Fase 02.5 distribui dados do servidor do laboratório. Antes de existir HTTP, precisa existir um formato de publicação confiável: o mesmo hash que nomeia o blob é o que o cliente verifica depois. Sem isso, autenticação e auditoria não têm o que proteger.

## Output
- `src/cecilia/remote/` com layout, hash, manifesto, publicação, catálogo, verificação e coleta
- `src/cecilia/cli.py` com `cecilia admin publish|verify|gc|catalog`
- Testes com Parquets sintéticos cobrindo publicação, deduplicação, corrupção e GC
- `pyproject.toml` com o entry point `cecilia` e a dependência `typer`
</objective>

<acceptance_criteria>

## AC-1: Publicação gera manifesto e catálogo corretos
```gherkin
Given um diretório com um ou mais arquivos .parquet
When `cecilia admin publish <dir> --dataset gaia_teste --version v1` é executado
Then cada arquivo vira um blob nomeado pelo SHA-256 do conteúdo
And o manifesto registra caminho relativo, blob, bytes, linhas e schema
And o catálogo lista o dataset com versão, bytes totais e hash do manifesto
```

## AC-2: Publicação é imutável e deduplica conteúdo
```gherkin
Given um dataset/versão já publicado
When a mesma versão é publicada novamente
Then a operação falha sem alterar o manifesto existente
And ao publicar outro dataset com o mesmo conteúdo, nenhum blob novo é copiado
```

## AC-3: Verificação detecta corrupção
```gherkin
Given um dataset publicado
When o conteúdo de um blob é alterado
Then `cecilia admin verify` reporta o blob corrompido e termina com código diferente de zero
```

## AC-4: GC remove apenas blobs órfãos
```gherkin
Given blobs referenciados por manifestos e um blob sem referência
When `cecilia admin gc --apply` é executado
Then o blob órfão é removido
And todos os blobs referenciados permanecem
```

## AC-5: Nomes e caminhos inválidos são rejeitados
```gherkin
Given um nome de dataset, versão ou caminho fora do padrão
When a publicação é solicitada
Then a operação falha com mensagem clara e nada é escrito fora da raiz configurada
```
